# Architectural Tenets

1. The platform owns governance.
2. Intent is the source of truth for requested change.
3. Git stores reviewable desired-state artifacts.
4. Execution is pluggable and replaceable.
5. Vendor-specific logic stays behind adapters.
6. Policy evaluation occurs before execution authorization.
7. Every change is verified.
8. Every change produces evidence.
9. Every change is reconciled.
10. Audit events are immutable and attributable.
11. Human approval remains explicit.
12. Security defaults to least privilege.
13. Secrets never enter domain payloads or Git.
14. Contracts are versioned.
15. Change models are versioned.
16. Evidence is tamper-evident and retention-aware.
17. External systems are integrations, not architectural centers.
18. AI is an assistant, never an approver or executor.
19. Domain boundaries precede service boundaries.
20. Architecture changes require documented decisions.
